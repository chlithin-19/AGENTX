# Atlas Verification Layer

**Module Namespace:** `backend/atlas/verifier/`  
**Architecture Reference:** `AGENTX_TO_ATLAS_ARCHITECTURE_v2.md` Section 16, 41 & 42

This directory contains the independent verification engine responsible for validating agent claims before results are surfaced to users or executed as side effects.
As per Phase 2A constraints, no verification rules are executed yet.

## Evidence Classes:
1. `MODEL_CLAIM`: Unverified statement generated by the LLM.
2. `TOOL_RESULT`: Data returned directly by a tool execution.
3. `DATABASE_RECORD`: Authoritative transactional record from PostgreSQL.
4. `RAG_SOURCE`: Verifiable citation from the institutional knowledge base.

## Core Rules:
- An LLM-generated claim without supporting evidence is never treated as verified ground truth.
- Conflicting evidence or broken constraints trigger a `partial` or `failed` workflow status instead of false success.
