# Phase 09-01 Implementation Plan: Priority A — Reliable AI Inference & Provider Routing

## Objective
Establish verified, highly reliable AI inference for the Atlas Campus Platform. Eliminate network hangs caused by the stalled OpenAI-compatible endpoint by implementing native Google GenAI REST SSE streaming with multi-tier model fallback (`gemini-3.5-flash` -> `gemini-3.5-flash-lite` -> local degraded mode). Enable high-quality general-purpose reasoning while strictly preserving evidence-grounded campus multi-agent responses.

## Key Changes
1. **Native Google GenAI SSE Streaming Integration (`backend/server.js`)**:
   - Refactor `streamLLM` and `reason` in `backend/server.js`.
   - Use native Google GenAI REST endpoint `https://generativelanguage.googleapis.com/v1beta/models/${model}:streamGenerateContent?alt=sse&key=${key}` and `:generateContent?key=${key}`.
   - Parse standard Gemini SSE stream candidate parts: `o.candidates[0].content.parts[0].text`.
   - Default to verified reachable models: `gemini-3.5-flash` and `gemini-3.5-flash-lite`.
2. **Multi-Tier Robust Fallback Architecture**:
   - Tier 1: Local Ollama (if running and healthy, checked with rapid 1s timeout).
   - Tier 2: Primary Cloud Model (`gemini-3.5-flash`).
   - Tier 3: Secondary Lightweight Cloud Model (`gemini-3.5-flash-lite`).
   - Tier 4: Degraded Offline Campus Mode (immediate, informative notice without hanging).
3. **General-Purpose Question Answering Support**:
   - When user queries general domain knowledge (e.g., mathematics, science, literature, coding concepts) outside campus datasets, stream genuine LLM reasoning rather than rejecting with a cold out-of-domain error.
   - For campus-specific claims (attendance, backlogs, grades, circulars), strictly ground answers in SQLite records and RAG citations.
4. **Automated Test Suite (`backend/tests/reliable_inference.test.js`)**:
   - Test Gemini SSE stream payload parsing.
   - Test fallback behavior when provider returns 429/500/timeout.
   - Test that degraded mode immediately yields helpful local offline context without stalling.
   - Test that general queries produce streaming tokens while campus queries ground in SQLite.

## Verification
- Run backend test suite: `npm --prefix backend test` (including new inference test).
- Send live general-purpose query via `/api/chat` SSE endpoint and verify real streaming tokens.
- Send live campus query via `/api/chat` and verify multi-agent synthesis.
- Measure TTFT (Time To First Token) to verify sub-2000ms cloud streaming.
