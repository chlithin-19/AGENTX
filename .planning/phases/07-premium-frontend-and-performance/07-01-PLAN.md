# Plan 07-01: Premium Frontend Polish, Accessibility Foundations & Performance Optimization

## Context & Objectives
Polish the established Atlas frontend design system ("Ethereal Editorial Tech"), enforce WCAG 2.1 AA accessibility foundations (`:focus-visible` rings and `prefers-reduced-motion` overrides), wire approval-required confirmation action badges directly into the chat workspace, and ensure responsive layout stability across mobile, tablet, and desktop breakpoints.

## Tasks

1. **Accessibility Foundations (`App.css`):**
   - Add global `:focus-visible` interactive keyboard focus rings (2px solid cobalt with 2px offset).
   - Add `@media (prefers-reduced-motion: reduce)` overrides to suppress non-essential animations for users with motion sensitivity.

2. **Chat Workspace & Consequential Action Confirmation (`ChatArea.jsx`):**
   - Wire `m.action.confirmationToken` into `/api/atlas/actions/confirm` with single-use server validation.
   - Render verified action proposal badge ("🛡️ Verified Action Proposal (Approval Required)").

3. **Subviews Polish & Dynamic States:**
   - Academics View: Real attendance shortfall monitoring and network error recovery.
   - Campus View: Facilities status grid and durable SQLite ticketing history.
   - Events View: Real-time registered counts and live registration workflow.
   - Communication View: Official circulars with category filters and live broadcast feed.

4. **Production Build & Asset Performance:**
   - Verify Vite production build creates optimized JS/CSS bundles with gzip compression.

## Acceptance Criteria
- [x] Keyboard navigation outlines and reduced motion media queries active across all components.
- [x] Action confirmation proposals execute through `/api/atlas/actions/confirm`.
- [x] All 4 campus views render live metrics with graceful offline fallbacks.
- [x] Vite production build passes with 0 errors.
