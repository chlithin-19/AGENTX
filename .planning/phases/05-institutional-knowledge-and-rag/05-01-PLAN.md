# Plan 05-01: Institutional Knowledge, Validated RAG Ingestion, Freshness Tracking & Citation Provenance

## Context & Objectives
Implement a hardened, grounded institutional knowledge and RAG subsystem. Documents must undergo schema validation, chunk integrity hashing (SHA-256), freshness verification, and prompt injection neutralization. Every campus answer drawn from institutional knowledge must include tamper-resistant citation provenance.

## Tasks

1. **Document Validation & Integrity Pipeline (`validator.js`):**
   - Implement `validateDocument(doc)`: verifies title, sourceId, category, effectiveDate, and minimum chunk size.
   - Compute SHA-256 chunk hash (`chunkHash`) for cryptographic provenance tracking.
   - Freshness tracking: check document age against institutional freshness thresholds.

2. **Hardened Semantic Chunk Retriever (`retriever.js`):**
   - Treat retrieved documents as passive text (neutralize prompt injections).
   - Return structured citations containing `documentId`, `title`, `section`, `chunkId`, `chunkHash`, and `lastUpdated`.
   - Implement relevance thresholding so weak matches are discarded rather than hallucinated.

3. **Institutional Document Corpus Expansion (`documents/`):**
   - Add authoritative institutional guidelines:
     - `academic_regulations.md`: Grading system, 75% attendance rule, condonation policy, detention criteria.
     - `campus_facilities.md`: Comprehensive timings for central library, student mess, gym, healthcare clinic.
     - `placement_guidelines.md`: Tier-based placement eligibility, interview rules, company criteria.
     - `student_conduct.md`: Grievance redressal, anti-ragging regulations, ethical conduct.

4. **Automated RAG & Knowledge Test Suite (`tests/knowledge_rag.test.js`):**
   - Test document validation (valid schema accepted, invalid rejected).
   - Test cryptographic chunk hashing and citation provenance.
   - Test freshness classification and warning flags.
   - Test search relevance and precision across policies and regulations.
   - Test prompt-injection neutralization in document content.
   - Test honest boundary behavior when knowledge is missing or unindexed.

## Acceptance Criteria
- [x] All documents undergo structural schema and freshness validation.
- [x] Citations carry cryptographic chunk hashes and verifiable source metadata.
- [x] Stale documents trigger institutional freshness notices.
- [x] RAG queries return zero hallucinations when query is outside the corpus.
- [x] 100% of knowledge tests pass; full test suite passes with 0 failures.
