# Plan 03-01: Super-Agent Intelligence, Multi-Intent Decomposition & Grounded Question Answering

## Context & Objectives
Empower the Atlas multi-agent system with robust intent understanding, sub-query decomposition for multi-intent questions, contextual conversation continuity, honest boundary handling for unsupported/ambiguous inquiries, and evidence-grounded response synthesis.

## Tasks

1. **Enhanced Intent Classification & Query Decomposition (`backend/atlas/orchestrator/orchestrator.js`):**
   - Implement `decomposeQuery(query)`: separates compound inquiries (e.g. "Check my attendance and tell me library hours") into targeted agent-specific sub-intents.
   - Handle ambiguous and out-of-domain questions with transparent, non-hallucinated explanations.
   - Support conversation history context (`history` parameter) to resolve follow-up questions.

2. **Agent Query Handling Hardening:**
   - **Academic Agent (`academic.js`):** Support queries for department benchmarks, skill profiles, attendance shortfall alerts, and placement statistics from real `campus.db`.
   - **Campus Agent (`campus.js`):** Support facility operating hours (Library, Cafeteria, Sports, Health Center), room locations (Lab 204, Academic Block), and maintenance requests.
   - **Event Agent (`event.js`):** Query upcoming events, hackathons, and generate calendar action payloads.
   - **Communication Agent (`communication.js`):** Search official circulars (#104, #98, #22) and prepare broadcast proposals.

3. **Evidence-Grounded Response Synthesis (`orchestrator.js`):**
   - Synthesize coherent markdown responses from multi-agent outputs.
   - Deduplicate and format verified knowledge citations with chunk provenance tags.
   - Provide clear call-to-action buttons/chips for actionable responses.

4. **Automated Intelligence Test Suite (`backend/tests/intelligence.test.js`):**
   - Test single-intent question answering across all 4 domains.
   - Test compound multi-intent questions ("attendance + events", "cgpa + facilities").
   - Test out-of-domain/unsupported inquiries (verifying honest limitations without hallucination).
   - Test follow-up conversation context resolution.
   - Test unauthorized inquiries (permission boundaries).

## Acceptance Criteria
- [x] Multi-intent queries are parsed into discrete agent tasks with targeted sub-inputs.
- [x] Responses are strictly grounded in verified data, database records, and knowledge docs.
- [x] Unsupported or out-of-scope inquiries explain system boundaries honestly.
- [x] All 4 agents return typed structured payloads and markdown summaries.
- [x] Complete automated test suite passes with 0 failures; frontend builds cleanly.
