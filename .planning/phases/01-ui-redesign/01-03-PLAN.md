# Plan 01-03: Payrot-Inspired Home Hero, Constellation & Notched Architecture

## Goal
Implement the flagship Payrot-inspired Home landing experience in `HomeView.jsx` as specified in `01-UI-SPEC.md`, featuring the central Atlas Core hologram, 4 satellite agent cards with SVG leader connectors, oversized translucent watermark, notched architectural transitions, capability trio, and deep midnight navy proof module.

## Proposed Changes

### 1. Hero Constellation Composition in `HomeView.jsx`
- Giant translucent background watermark: **`ATLAS`** (`clamp(80px, 14vw, 160px)`, opacity 4–6%).
- Central Atlas Core hologram: 3D orbital sphere with cyan glow (`--atlas-shadow-glow`).
- Four asymmetric floating satellite agent cards populated with real demo data:
  1. **Academic Agent (Top Left):** Royal blue badge, displaying Alex Kumar / Priya Sharma (`CGPA 8.92`, `Attendance 88% ✓`).
  2. **Campus Agent (Top Right):** Teal badge, displaying Central Library & Lab 204 (`14 Desks Available`).
  3. **Event Agent (Bottom Left):** Violet badge, displaying Atlas 36h National Hackathon (`Registration Open`).
  4. **Communication Agent (Bottom Right):** Amber badge, displaying Circular #104 Midterm Advisory (`Verified ✓`).
- Fine hairline SVG connector lines with circular node pips visually connecting the 4 cards to the central Atlas Core.
- Hero typography:
  - Eyebrow: `CAMPUS INTELLIGENCE LAYER` pill with glowing cobalt dot.
  - Headline:
    ```text
    ATLAS
    YOUR CAMPUS. ONE INTELLIGENT SYSTEM.
    ```
  - Subtitle: Clear editorial narrative on private, multi-agent campus AI.
  - Dual action pills: `Ask Atlas Anything →` (triggers view switch to `chat`) and `Explore Architecture ↓` (scrolls down).

### 2. Notched Architectural Transition & Capability Trio
- Sculptural container featuring top inverted U-curve notch cradling the floating badge: `4 SPECIALIZED AGENTS · ZERO HALLUCINATIONS`.
- Trio of capability cards with clean typography and icons:
  1. *Academic Analytics & Placement* (Kaggle benchmark tracking, attendance threshold monitors).
  2. *Campus Infrastructure* (Room navigation, facilities operating hours, maintenance ticketing).
  3. *Verified Knowledge & Circulars* (Authoritative document citations, grounded policy retrieval).

### 3. Deep Midnight Navy Contrast Module
- Deep midnight navy (`--atlas-navy-deep: #0B1528`) anchor container with concave upper boundary.
- Headline: `POWERING CAMPUS OPERATIONS WITH COMPLETE PRIVACY`.
- Proof metric blocks:
  - `5` Authoritative Demo Profiles Loaded
  - `4` Coordinated Specialized Agents
  - `100%` Grounded RAG Citation Provenance
  - `< 150ms` Edge Intent Classification Latency
- Action pill: `Launch Campus Assistant →` (routes to `chat`).

### 4. Wire `HomeView.jsx` into `App.jsx`
- Mount `HomeView` when `activeTab === 'home'`.
- Pass navigation callback `onNavigate={(tab) => setActiveTab(tab)}`.
