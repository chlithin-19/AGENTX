# Plan 01-06: Responsive Polish, WCAG 2.1 AA Accessibility & End-to-End Verification

## Goal
Complete responsive design integration across all viewports (mobile 375px, tablet 768px, desktop 1280px+), enforce WCAG 2.1 AA accessibility standards (contrast ratios, 2px focus halos, ARIA semantics, reduced-motion rules), verify production build integrity, and confirm zero diff on backend files.

## Proposed Changes

### 1. Viewport Breakpoints & Responsive CSS in `App.css`
- Add comprehensive media queries:
  - `@media (max-width: 640px)` (Mobile):
    - Ensure zero horizontal overflow (`overflow-x: hidden`).
    - Home hero constellation collapses cleanly into a vertical card stack with graceful SVG line adaptation.
    - Chat container paddings reduce to 12px; floating omnibar adjusts cleanly above mobile keyboard.
    - Sub-view metric grids stack into a single column.
  - `@media (min-width: 641px) and (max-width: 1024px)` (Tablet):
    - 2-column grid for satellite agent cards and capability cards.
    - Floating header padding and font sizes adapt proportionally.
  - `@media (min-width: 1440px)` (Wide Desktop):
    - Content wrapper centered with max-width `1400px`.

### 2. Accessibility (WCAG 2.1 AA) Implementation
- Focus Management:
  - Add global focus rule: `:focus-visible { outline: 2px solid var(--atlas-accent-cobalt); outline-offset: 2px; }`.
- ARIA Attributes & Semantic Landmarks:
  - Update `Header.jsx`: navigation uses `role="tablist"` and items use `role="tab"` with `aria-selected={activeTab === tab}`.
  - Update `MobileNav.jsx`: drawer uses `role="dialog"` with `aria-modal="true"`.
  - Update `ChatArea.jsx`: streaming response container includes `aria-live="polite"`.
  - Icon-only buttons (send, mic, clear, refresh, close) receive explicit `aria-label` tags.
- Reduced Motion:
  - Add `@media (prefers-reduced-motion: reduce)` rule disabling orbital pulsing and infinite rotations.

### 3. Verification & Zero-Backend-Diff Gate
- Run `npm --prefix frontend/frontend run build` and ensure clean exit 0.
- Execute git diff inspection ensuring zero changes to `backend/` or database files.
