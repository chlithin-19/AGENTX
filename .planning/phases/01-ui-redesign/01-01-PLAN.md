# Plan 01-01: Design Tokens, CSS Foundation & Sculptural Base

## Goal
Establish the complete "Ethereal Editorial Tech" design system foundation in Vanilla CSS as specified by `01-UI-SPEC.md` and locked in `01-CONTEXT.md`. Transition the canvas from dark workstation (`#090a0f`) to pale sky mist (`#F4F8FC`) and pure crisp white (`#FFFFFF`) with midnight navy grounding blocks (`#0B1528`), electric cobalt accents (`#0062FF`), sculptural boundary tokens, and typography scales.

## Proposed Changes

### 1. HTML Fonts & Metadata
- Update `frontend/frontend/index.html` to load Google Fonts: `Plus Jakarta Sans` (weights 400, 500, 600, 700, 800) and `JetBrains Mono` (weights 400, 500).
- Set title to `Atlas — Campus Multi-Agent Intelligence`.

### 2. Design Tokens in `index.css`
- Replace legacy dark-mode variables with the authoritative 60-30-10 color distribution tokens:
  - Canvas & Light Surfaces: `--atlas-bg-canvas: #F4F8FC`, `--atlas-bg-canvas-alt: #EBF3FA`, `--atlas-surface-white: #FFFFFF`, `--atlas-surface-glass: rgba(255, 255, 255, 0.82)`, `--atlas-surface-tint: #EAF2F9`.
  - Secondary & Contrast Surfaces: `--atlas-navy-deep: #0B1528`, `--atlas-navy-card: #132238`, `--atlas-navy-border: rgba(255, 255, 255, 0.12)`.
  - Accent System: `--atlas-accent-cobalt: #0062FF`, `--atlas-accent-hover: #004EDB`, `--atlas-accent-soft: rgba(0, 98, 255, 0.08)`, `--atlas-accent-cyan: #38BDF8`.
  - Agent Identities: `--atlas-agent-academic: #2563EB`, `--atlas-agent-campus: #0D9488`, `--atlas-agent-event: #7C3AED`, `--atlas-agent-comm: #EA580C`.
  - Text Tokens: `--atlas-text-headline: #0A192F`, `--atlas-text-body: #334E68`, `--atlas-text-muted: #627D98`, `--atlas-text-on-dark: #F8FAFC`, `--atlas-text-on-dark-muted: #94A3B8`, `--atlas-watermark: rgba(10, 25, 47, 0.04)`.
  - Spacing Scale: `--atlas-space-xs: 4px`, `--atlas-space-sm: 8px`, `--atlas-space-md: 16px`, `--atlas-space-lg: 24px`, `--atlas-space-xl: 32px`, `--atlas-space-2xl: 48px`, `--atlas-space-3xl: 64px`, `--atlas-space-4xl: 96px`.
  - Radius Scale: `--atlas-radius-full: 9999px`, `--atlas-radius-2xl: 28px`, `--atlas-radius-xl: 20px`, `--atlas-radius-lg: 14px`, `--atlas-radius-md: 10px`.
  - Shadows & Glow: `--atlas-shadow-card`, `--atlas-shadow-floating`, `--atlas-shadow-glow`.
- Global resets: update `body` to `background-color: var(--atlas-bg-canvas)` and `color: var(--atlas-text-body)`.
- Scrollbar styles tuned for light frosted background.

### 3. Utility Classes & Geometric Curves in `App.css`
- Add utility classes for sculptural transitions: `.scalloped-container`, `.notched-badge-cradle`, `.watermark-text`, `.frosted-panel`, `.atlas-pill-btn`, `.atlas-badge`.
- Ensure standard box-sizing and non-breaking margin/padding behavior.
