# Plan 01-05: Campus Sub-Views & Settings Integration

## Goal
Implement cohesive, editorial sub-view components for the remaining five Atlas destinations (`AcademicsView`, `CampusView`, `EventsView`, `CommunicationView`, `SettingsView`), wrapping the existing `Integrations.jsx` within the Settings module. All views display real demo campus data, explicitly label demo records, and feature quick action chips bridging directly into Ask Atlas.

- Interactive action chip: `Ask Atlas to audit my attendance →` (navigates to `chat` with prompt).
- Visible badge: `DEMO DATA · KAGGLE BENCHMARKS`.

- Directory grid using real campus infrastructure from `demoCampus.js`:
  - Central Library: Study rooms, quiet hours, borrowing limits.
  - Academic Block A & B: Lab 204 (status: `14 Available Desks`).
  - Student Activity Center: Cafeteria, Sports Complex, Health Clinic.
- Maintenance ticketing card preview with issue submission form.
- Action chip: `Ask Atlas for facility hours or report maintenance →`.

### 3. `EventsView.jsx` (Campus Events & Hackathons)
- Campus event timeline using real event records from `demoEvents.js`:
  - *Atlas 36-Hour National Campus Hackathon 2026* (`Oct 24-25`, Registration Open, Main Auditorium).

### 4. `CommunicationView.jsx` (Official Circulars & Advisories)

### 5. `SettingsView.jsx` (Preferences & Integrations Gateway)
- System status overview card displaying:
  - Local Edge Engine: `Google Gemma 4 E2B` (`128K context`, CPU inference).
  - Cloud Reasoning Tier: `Google Gemini 3.8 Flash` (`@google/genai`).
