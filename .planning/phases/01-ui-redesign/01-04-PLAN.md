# Plan 01-04: Ask Atlas Chat Workstation & Multi-Agent Reasoning (ThoughtLine Integration)

## Goal
Transform the conversational workstation in `ChatArea.jsx` to the ethereal editorial aesthetic while preserving 100% of its SSE streaming, history, actions, and multimodal image capabilities. Unhide and integrate `ThoughtLine.jsx` to display real-time multi-agent execution steps during streaming, restyle message cards, and redesign the floating omnibar input.

## Proposed Changes

### 1. Integrate `ThoughtLine.jsx` for Multi-Agent Progress
- Import `ThoughtLine` in `frontend/frontend/src/components/ChatArea.jsx`.
- Replace the legacy inline step pill with `ThoughtLine`:
  - Activates when `isGenerating === true` or `currentStep !== null`.
  - Displays real step text from SSE stream (`data.step`, e.g. `"Routing to Atlas Campus Multi-Agent System"`).
  - Displays elapsed reasoning timer.
  - Automatically settles and collapses upon completion (`data.done: true`).
  - Never fabricate fake internal reasoning steps; only reflect genuine backend step transitions.

### 2. Message Presentation Restyle
- Centered container (`max-width: 920px`) with generous breathing room.
- User message bubble:
  - Right-aligned with soft cobalt tint (`rgba(0, 98, 255, 0.06)`), hairline border (`rgba(0, 98, 255, 0.15)`), and deep ink navy text (`#0A192F`).
- Agent message card:
  - Left-aligned, crisp white surface (`#FFFFFF`) with multi-stage shadow (`var(--atlas-shadow-card)`), hairline border, and 24px padding.
  - Responding agent badge with domain color (e.g. Royal Blue for Academic, Teal for Campus).
  - Preserved markdown formatting, tables, code blocks, and images via `ImageCard.jsx`.
- Verified citations box:
  - If markdown text contains verified citations or chunk sources (`[Doc: ... #Section ...]`), render structured source chips with badge icons.

### 3. Redesigned Floating Omnibar Input
- Pinned floating pill container with frosted glass (`backdrop-filter: blur(16px)`).
- Campus quick prompt chips row above the input:
  - `"Show my academic standing and attendance"`
  - `"When is the Atlas 36h Hackathon?"`
  - `"Is Lab 204 available right now?"`
  - `"What are the library borrowing rules?"`
- Auto-expanding textarea with placeholder: `"Ask Atlas about academics, facilities, events, or circulars..."`.
- Circular cobalt send button with paper plane / arrow icon, disabled when input is empty or generating.

### 4. Preservation of Core Runtime Logic
- Keep `handleSend` SSE stream reader (`TextDecoder`, buffering, `data: { ... }` splitting).
- Keep `loadHistory` (`GET /api/history`) and `handleClearHistory` (`DELETE /api/history`).
- Keep `handleExecuteAction` for Calendar, Email, and LinkedIn actions.
- Keep language dropdown and Autopilot toggle in the chat controls.

- Existing SSE event parsing logic is not bypassed or replaced with mocks.
- Claims of chat functionality must never be based on frontend build success alone if end-to-end backend verification cannot be completed.
