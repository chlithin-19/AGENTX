# Plan 01-02: Global Navigation Shell, Floating Frosted Header & View Router

## Goal
Implement the modern Atlas application shell and zero-dependency 7-view navigation router in `App.jsx`, replacing the fixed 270px dark sidebar with the Payrot-inspired floating frosted-glass top header on desktop and a responsive slide-down drawer with persistent bottom tabs on mobile (< 640px).

## Proposed Changes

### 1. Zero-Dependency View Router in `App.jsx`
- Support 7 active destinations:
  1. `home` (Home landing experience)
  2. `chat` (Ask Atlas conversational workspace)
  3. `academics` (Academic analytics & placement)
  4. `campus` (Campus facilities & navigation)
  5. `events` (Campus events & hackathons)
  6. `communication` (Official circulars & advisories)
  7. `settings` (OAuth integrations & preferences)
- Initialize `activeTab` by inspecting `window.location`:
  - If URL matches `/chat` or `?tab=chat` -> `chat`
  - If URL matches `/integrations` or `?tab=integrations` or `/settings` -> `settings`
  - If URL matches `/academics` -> `academics`
  - If URL matches `/campus` -> `campus`
  - If URL matches `/events` -> `events`
  - If URL matches `/communication` -> `communication`
  - Defaults to `home`.
- Push browser history state on tab change via `window.history.pushState` so the browser back/forward buttons work naturally via a `popstate` event listener.
- Retain container structure for mounting current active view with smooth fade-in transition.

### 2. Desktop Floating Frosted Header (`components/Header.jsx`)
- Create `frontend/frontend/src/components/Header.jsx`:
  - Pinned with `position: sticky; top: 16px; margin: 0 auto; max-width: 1240px; z-index: 100;`.
  - Floating pill container with `backdrop-filter: blur(20px)`, background `var(--atlas-surface-glass)`, and `border-radius: var(--atlas-radius-full)`.
  - Left: Logo monogram with cobalt/cyan gradient, geometric `ATLAS` text, and green pulsing status dot ("Hybrid Edge-Cloud Active").
  - Center: Segmented track containing all 7 navigation items with smooth active pill indicator.
  - Right: Quick CTA pill button: `Ask Atlas →` with cobalt background that routes directly to the `chat` tab.

### 3. Responsive Mobile Navigation (`components/MobileNav.jsx`)
- Create `frontend/frontend/src/components/MobileNav.jsx`:
  - Pinned top compact 56px frosted bar with brand on left, active view label, and hamburger toggle button.
  - Slide-down full-screen frosted drawer displaying all 7 views with 48px touch targets, domain icons, and status indicators.
  - Persistent bottom navigation bar pinned to bottom of mobile viewports (< 640px) with 4 key destinations: `Home`, `Ask Atlas` (elevated center button), `Academics`, and `Campus`.

### 4. Styles in `App.css`
- Add styling rules for `.atlas-header-floating`, `.atlas-nav-pill-track`, `.atlas-nav-item`, `.atlas-mobile-header`, `.atlas-mobile-drawer`, `.atlas-bottom-bar`.
