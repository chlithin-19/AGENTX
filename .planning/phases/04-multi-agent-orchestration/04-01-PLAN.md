# Plan 04-01: Multi-Agent Orchestration, Bounded Timeouts, Safe Concurrency & Fault Recovery

## Context & Objectives
Empower the Atlas orchestrator with industrial-grade reliability: explicit dependency-aware DAG task execution, safe concurrency for independent tasks, bounded timeouts via `AbortController`, client cancellation support, idempotent retries with exponential backoff, partial-result recovery, and per-agent progress streaming over SSE.

## Tasks

1. **DAG Task Planning & Dependency Resolution (`orchestrator.js`):**
   - Enhance `decomposeQuery()` and task planner to produce structured task DAGs with explicit `dependsOn: []` relationships and typed handoff payloads.
   - Enforce resource limits: maximum 6 tasks per plan, input size boundaries.

2. **Bounded Execution Timeouts & Cancellation (`orchestrator.js`):**
   - Wrap agent executions with configurable `AbortController` timeouts (default 5000ms).
   - Support upstream cancellation via optional `abortSignal` parameter (e.g. client disconnects SSE stream).

3. **Safe Concurrency & Controlled Parallelization:**
   - Group tasks into dependency-free waves or execute independent tasks concurrently with bounded concurrency (max 3 concurrent agents).
   - Safeguard dependent tasks by executing sequentially and passing typed outputs.

4. **Idempotent Retry Policy:**
   - Define `isIdempotent(agent, action)`: read-only queries are retryable up to 2 times with backoff; mutating/drafting actions never retry automatically.

5. **Partial Fault Isolation & Transparent Recovery:**
   - Isolate task failures with `Promise.allSettled` and safe error boundary wrappers.
   - Synthesize partial responses transparently when non-critical agents time out or fail.

6. **Granular SSE Progress Streaming (`server.js` & `index.js`):**
   - Expose `onProgress` callback in `orchestrateAtlas()` to stream live per-agent start, complete, and retry steps into `/api/chat` SSE without violating event schema.

7. **Automated Orchestration Test Suite (`backend/tests/orchestration.test.js`):**
   - Verify parallel execution of independent multi-agent tasks.
   - Verify timeout abort behavior when agent exceeds threshold.
   - Verify idempotent retry on transient failures.
   - Verify non-idempotent operations are never retried.
   - Verify partial-result synthesis when one agent fails.
   - Verify cancellation propagation when `AbortSignal` triggers.

## Acceptance Criteria
- [x] Independent multi-agent tasks execute in parallel without race conditions.
- [x] Agent execution is strictly bounded by configurable timeouts (raising clean ETIMEDOUT).
- [x] Partial failure recovers gracefully with `status: 'partial'` and honest disclaimers.
- [x] Progress callbacks stream clean SSE `step` updates to frontend.
- [x] 100% of orchestration tests pass; existing 55 tests continue passing.
